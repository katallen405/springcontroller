Add / remove springs
What do these fields mean?
Link
The robot link the spring attaches to.
name
Identifier used to remove/update this spring later -- must be unique.
target x/y/z
World-frame point (m) the spring pulls the attachment point toward (position springs only).
local x/y/z
Attachment point (m), in the link's own local frame -- e.g. (0,0,0) is the link origin.
stiffness
Spring constant k (N/m). Force grows linearly with distance from target/rest length.
damping
Damping coefficient b (N·s/m). Resists velocity, independent of distance.
rest length
Distance (m) from target at which the spring exerts zero force (position springs only).
inner/outer radius
Dead-zone/ramp band (m) around rest length -- no force inside inner radius, full stiffness beyond outer radius, ramped in between (position springs only).
normal x/y/z
Unit direction fixed in the link's local frame (e.g. a tool's face normal) that gets pulled to point at the world-frame target -- a "look at" constraint, not a position pull (orientation springs only).

Orientation spring: "local normal" is a direction fixed in the link's local frame (e.g. a tool's face normal), and "target" is the world point that direction gets pulled to point at -- a "look at" constraint, not a position pull. Normal should be a unit vector.
